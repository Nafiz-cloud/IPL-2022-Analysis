# IPL-2022-Analysis

This project presents an exploratory data analysis (EDA) of the IPL 2022 dataset using Python. The objective was to extract meaningful insights from match data and visualize performance patterns using interactive charts.

📌 Project Overview

The analysis focuses on:

Match outcome trends (Chasing vs Defending wins)

Team performance insights

Distribution of match results

Data cleaning and transformation techniques

Raw data was processed and analyzed to uncover patterns that influence match outcomes.

🛠️ Technologies Used

Python

Pandas – Data cleaning and manipulation

Plotly – Interactive data visualization

Jupyter Notebook

📊 Key Insights

Identified win distribution based on match type (runs vs wickets).

Compared team performances across the tournament.

Visualized trends to better understand strategic advantages in IPL matches.
